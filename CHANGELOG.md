# Changelog

All notable changes to NFA Switcher are documented here.

## [1.0.0] - 2026-09-26

Initial Fabric 1.21.11 release.

### Added

- Microsoft device-code login with Azure and Xbox fallback flows.
- Cookie-alt importing from Netscape files, JSON arrays, raw headers, pasted text, and files.
- Microsoft refresh-token importing, including bulk and `email:token` formats.
- Minecraft session-token importing with official profile lookup.
- Offline/cracked account creation, including bulk generation and vanilla offline UUIDs.
- Account manager accessible from the title screen, Multiplayer screen, and the `U` keybind.
- Account search, pagination, deletion, restoration of the original launcher session, and login status banners.
- Local account storage under `.minecraft/config/nfaswitcher/accounts.json`.
